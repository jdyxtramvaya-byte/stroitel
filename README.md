# 🏗️ Строитель

Мобильное PWA-приложение для ведения строительных объектов.

## Цель

Объединить в одном простом интерфейсе:
- 📐 замеры помещений и расчёты площадей;
- 🧱 материалы и расчёт количества;
- 💰 сметы и стоимость работ;
- 🛒 список покупок;
- 📸 дневник объекта;
- 👷 бригаду;
- ⚠️ проблемы и замечания;
- 📄 документы и отчёты.

## Принцип

Приложение должно быть удобным прямо на объекте: большие элементы управления, минимум ручного ввода, работа без интернета и локальное сохранение данных.

## Первый этап

1. Объекты
2. Помещения
3. Замеры
4. Автоматические расчёты
5. Материалы
6. Смета
7. Локальное хранение

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- PWA
- IndexedDB (следующий этап)

Проект развивается поэтапно.
