# Строитель 🏗️

Мобильное PWA-приложение для строительных объектов.

Работает прямо в браузере — без Flutter, Android Studio и установки отдельного приложения.

## Сейчас работает
- объекты с адресом и заказчиком;
- локальное сохранение;
- помещения и замеры;
- автоматический расчёт площади пола и стен;
- адаптивный интерфейс для телефона;
- PWA и добавление на главный экран.
