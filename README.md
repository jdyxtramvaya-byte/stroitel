# Строитель

Flutter-приложение для строителей: объекты, замеры, материалы, сметы, закупки и дневник работ.

## MVP уже реализован

- создание и список строительных объектов;
- локальное сохранение данных;
- карточка объекта;
- добавление помещений и замеров;
- автоматический расчёт площади пола и стен;
- разделы для материалов, сметы, закупок, дневника и проблем;
- Material 3 интерфейс;
- базовый widget test.

## Стек

- Flutter / Dart;
- Material 3;
- shared_preferences для локального MVP-хранилища.

Flutter рекомендует разделять UI и data-слои по мере роста приложения; после стабилизации MVP код будет разнесён по feature/domain/data слоям.

## Запуск

Если Flutter SDK уже установлен:

```bash
flutter create .
flutter pub get
flutter test
flutter run
```

Команда `flutter create .` добавляет платформенную обвязку Android/iOS/web к исходникам приложения.

## APK через GitHub Actions

В репозитории добавлен workflow сборки Android. После push GitHub Actions создаёт APK как artifact.

Следующий этап — полноценные замеры: двери/окна/проёмы, сохранение отдельных измерений, расчёт материалов и затем смета.
